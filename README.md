# Agentic AI-Powered Intrusion Detection System (IDS)

This project is an advanced Intrusion Detection System (IDS) that leverages a multi-agent AI framework to autonomously detect, investigate, and respond to cybersecurity threats in real-time. The system is designed to simulate a Security Operations Center (SOC) where AI agents collaborate to analyze network traffic, enrich data with external threat intelligence, and take decisive action.

## Key Features

*   **Multi-Agent Framework:** The system is built around a team of specialized AI agents, each with a distinct role:
    *   **Anomaly Agent:** The primary investigator, responsible for analyzing suspicious IP addresses.
    *   **Coordinator Agent:** The decision-maker, which takes action based on the Anomaly Agent's findings.
    *   **Signature Agent:** A proactive hunter that scans for known threats and initiates investigations.
*   **Automated Threat Intelligence Correlation:** The system automatically queries external threat intelligence APIs (AbuseIPDB and VirusTotal) to enrich its analysis and make more accurate, context-aware decisions.
*   **Machine Learning-Powered Anomaly Detection:** A pre-trained Isolation Forest model is used to detect anomalies in network traffic, triggering the reactive defense workflow.
*   **Immutable Logging with Blockchain:** All critical actions and decisions are logged to a simple blockchain, ensuring an immutable and tamper-proof audit trail.
*   **Web-Based Dashboard:** A Flask-based web interface provides a real-time view of the system's operations, including:
    *   Agent status and metrics.
    *   A dynamic, filterable chart of agent activity.
    *   A log of recent agent activities.
    *   A view of the blockchain ledger.

## How It Works

The system operates in two primary modes:

1.  **Reactive Defense:** The `main.py` script simulates the analysis of network traffic. When the machine learning model detects an anomaly, it triggers the **Anomaly Agent** to investigate the associated IP address. The Anomaly Agent uses its tools to gather data, calculates a confidence score, and produces a detailed report. This report is then passed to the **Coordinator Agent**, which decides whether to block the IP or log it for human review.
2.  **Proactive Defense:** The **Signature Agent** periodically scans for new threats from external intelligence feeds. When a new threat is identified, it triggers the **Anomaly Agent** to perform a full investigation, following the same workflow as the reactive defense.

## Setup and Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/TheCodeVirtuoso/Agentic-AI-IDS.git
    cd Agentic-AI-IDS
    ```
2.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Configure your API keys:**
    *   Rename the `.env.example` file to `.env`.
    *   Open the `.env` file and add your API keys for AbuseIPDB, VirusTotal, and Google Generative AI.

## Usage

1.  **Run the main application:**
    ```bash
    python main.py
    ```
    This will start the SOC orchestrator, and you will see the agents' activity in your terminal.
2.  **Run the dashboard:**
    ```bash
    python dashboard.py
    ```
    This will start the Flask web server. You can access the dashboard by opening your web browser and navigating to `http://127.0.0.1:5000`.

## Project Structure

*   `main.py`: The main entry point for the application.
*   `agents.py`: Defines the AI agents and their prompts.
*   `tools.py`: Implements the tools used by the agents (e.g., API clients, logging functions).
*   `blockchain.py`: Implements the simple blockchain for immutable logging.
*   `dashboard.py`: The Flask web application for the dashboard.
*   `.env`: Stores the API keys.
*   `data/`: Contains the dataset used for anomaly detection.
*   `models/`: Stores the pre-trained machine learning model and scaler.
*   `*.log`: The log files generated by the system.
